# TenderLens Security Policy

Please refer to the comprehensive [Application Security Standard & AI Audit Protocol](docs/SECURITY.md) for our 20-point security specification, input validation, authentication, Row-Level Security (RLS), and pre-launch verification gates.

## Reporting a Vulnerability

If you discover a security vulnerability in TenderLens, please report it privately to the maintainers. Do not disclose security vulnerabilities publicly or commit sensitive credentials to source control.
