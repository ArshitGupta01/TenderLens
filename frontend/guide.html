02 / STRATEGY PREVIEW

What the new tools do

The preview uses tender and bidder values that you enter. It does not read tender files, save the submitted form, or make a legal or eligibility decision.

  1. Use clarification prompts to identify questions you may want to ask through the official tender channel.
  2. Review possible capability gaps. TenderLens does not list or verify consortium partners.
  3. Download the checklist as a CSV draft; entered values are not supporting evidence.
  4. Use the EMD figure as a cash scenario only. The tool does not confirm exemptions or permitted instruments.
  5. If you choose public-source search, the tender title and portal are sent to the configured search provider. Search results need manual verification.

04 / USEFUL WORDS

A short glossary

Tender documents use a lot of abbreviations. Here are the ones used on this site.

Tender
A buyer’s request for companies to offer goods, work or services.
ATC
“Additional Terms and Conditions”: extra rules added by the buyer.
Corrigendum
An official notice that changes or clarifies an earlier tender.
Clause
One numbered rule or paragraph inside a tender file.
Evidence
A document or record that helps show whether a requirement is met.
Bidder profile
Basic details about the business preparing a bid. Save a local draft or sync it to your signed-in account.

05 / OPTIONAL LIVE SEARCH

Turn on current tender search

This needs the TenderLens backend and a TinyFish API key. The key stays on the server; never put it in the website code.

  1. Install uv and sync the project dependencies.
  2. Copy .env.example to .env, then add your TinyFish key to TINYFISH_API_KEY.
  3. Start the API with uv run uvicorn backend.main:app --reload.
  4. In another terminal, run python -m http.server 4177 and open http://localhost:4177.
  5. Open “Search current tender notices” and submit a phrase. Only that phrase and the selected portal are sent.

Other backend features: GEMINI_API_KEY turns on clause/conflict analysis, while TAVILY_API_KEY enables the backup web search. Both are optional for the website and account pages; the model setting defaults to gemini-3.8-flash.

What is connected? Live search uses the backend, and the separate Strategy tools page builds a preview from values you enter. Tender fetching and source-document scorecard review are not connected to a webpage form.

06 / ACCOUNTS AND SAVED TENDERS

Set up sign-in once

TenderLens uses Supabase Auth and Supabase Postgres for accounts. FastAPI provides the public project settings and continues to run live tender search. User rows are protected with database policies.

Create an account ↗Already have an account? Sign in
  1. Create a Supabase project. Copy its Project URL and publishable key from the Connect dialog into SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY in your private .env. The publishable key is designed to be exposed to the browser; never use a secret or service-role key here.
  2. Run supabase/setup.sql once in Supabase Dashboard → SQL Editor. It creates the bidder-profile and saved-tender tables and locks rows to their account with row-level security.
  3. In Supabase Authentication, enable Email and Google. For Google, create a Google OAuth client, copy its client ID and secret into the Supabase Google provider settings, and add the callback URL shown by Supabase to Google Cloud.
  4. Add http://127.0.0.1:4177/** and http://localhost:4177/** under Supabase Authentication → URL Configuration → Redirect URLs. Set the site URL to the address you use locally.
  5. For email confirmation and password reset in production, configure a trusted SMTP provider in Supabase. The built-in test mailer is intended for limited development use.
  6. Restart FastAPI with uv run uvicorn backend.main:app --reload and serve the pages at http://127.0.0.1:4177. Sign in, update your profile, then test saving a link from a live search result.

Keep secrets out of chat and GitHub. Google OAuth client secrets and SMTP credentials belong in the Supabase Dashboard. TenderLens only needs the Supabase URL and browser-safe publishable key in the private local environment file. Do not send us keys in chat.

Not needed for this connection: a direct database password or Supabase secret key. The browser uses Supabase Auth and Postgres Data API with row-level security; FastAPI does not bypass those policies.
